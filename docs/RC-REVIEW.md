# RCレビューの追跡

添付v0.6.3-rc.2のFINAL_REVIEW.md、VALIDATION.md、docs/rc1/AUDIT_REPORT.mdを読み、次を確認しました。実環境情報を含み得る元のレビュー本文・生ログは公開リポジトリへ取り込まず、ここに追跡結果だけを残します。

| RCの論点 | 今回の扱い |
|---|---|
| 履歴キャッシュ応答競合 F01 | RCの中止・世代判定を保持。Nodeと実Chromium回帰で確認 |
| ビルド検証印 F02 | 失敗時の印削除・race必須を保持。5件の失敗分岐試験と全体ビルドで確認 |
| バックアップ整合性 F03 | 復元前size/SHA-256全件検証を保持。実Goの単体試験で確認。secrets.env追加と旧manifest互換を追加 |
| インシデント500件上限 | 表示用だけに制限。通知のページ取得、ID検索、pending保持・prune保護、キュー巡回を追加。1201件・700件の回帰で確認 |
| 正規依存・本番build・vet・race | go.sumを確定して実行。最新安定Goで依存脆弱性検査を実行 |
| Go SQLite | 実moderncドライバで保存・prune・ページ処理・再オープンを検証。運用中の巨大旧DB複製は未検証 |
| CQL driverの初期接続・停止・wire frame割当 | 実依存でコンパイル。TCP/CQL OPTIONS fixtureは回帰試験あり。実ScyllaDB、driver認証/TLS/再接続の実験は未実施 |
| ブラウザ | 実Chromiumで21件を実行。接続図の非表示時の幅によるズーム中心変更を修正 |
| ARM64 | クロスビルド。ARM実機での起動・負荷は未検証 |
| systemd/TLS/カスタムunit | ファイル処理とコマンド列の単体試験。対象ホストでの導入・更新・失敗復元は未実施。標準パス以外を自動管理しない |
| 長期メモリ | 退役identityカウンター保持を修正。有限soakを実行。実時間2〜4週間の受入は未実施 |
| 通知の一部宛先成功・再送 | exactly-onceを保証しない。Alertmanager集約モードを追加、直接webhookと併用を禁止。停止・再起動・分断の限界を文書化 |

すべての未検証事項を解決済みとは扱いません。正式版の条件はVALIDATION.mdとUPGRADE.mdを参照してください。
